# 1.1.7 개인정보 공개 대조 초안

상태: **공식 SDK 배포물 조사 완료 / 최종 signed archive·실제 동작 대조 대기 / Connect 저장 안 함**.

[원본 선언과 해시](sdk-privacy-manifests.json)는 Google Mobile Ads 13.9.0·UMP 3.1.0의 공식 SwiftPM ZIP을 공식 checksum과 대조한 값이다. [Google 공개 안내](https://developers.google.com/admob/ios/privacy/data-disclosure)는 SDK manifest를 확인해 앱의 공개를 결정하도록 안내한다. 실제 export가 해당 버전을 사용하고 SDK manifest를 포함했는지 최종 산출물 검사에서 다시 확인한다.

현재 App Privacy의 5개 유형·추적 없음·신원 비연결은 SDK의 아래 선언과 맞지 않는다. 광고 데이터와 기타 진단 데이터도 선언되어 있고, 기기 ID는 추적에 사용되며 위치·광고 데이터·상호작용·기기 ID는 연결되는 데이터로 선언되어 있다. 최종 저장은 후보의 실제 광고/분석 설정과 산출물 검수 후 수행한다.

| 유형 | GMA 연결 | GMA 추적 | SDK 선언 목적 | UMP 추가 목적 |
|---|---|---|---|---|
| 대략적 위치 | 예 | 아니오 | 타사 광고·개발자 광고·분석 | 앱 기능 |
| 기기 ID | 예 | 예 | 타사 광고·개발자 광고·분석 | 없음 |
| 제품 상호작용 | 예 | 아니오 | 타사 광고·개발자 광고·분석 | 앱 기능 |
| 광고 데이터 | 예 | 아니오 | 타사 광고·개발자 광고·분석 | 없음 |
| 충돌 데이터 | 아니오 | 아니오 | 분석 | 없음 |
| 성능 데이터 | 아니오 | 아니오 | 타사 광고·개발자 광고·분석 | 앱 기능 |
| 기타 진단 데이터 | 아니오 | 아니오 | 타사 광고·개발자 광고·분석 | 없음 |

- 앱은 ATT 허용 전 광고 SDK를 초기화하거나 광고를 요청하지 않는다. 허용 시에도 `npa=1`을 유지한다. 이 설정이 기기 ID 추적 여부를 자동으로 지우지는 않는다.
- ATT 거부 시에도 필요한 UMP 동의 처리와 앱의 GA4 분석은 별개로 동작한다. 따라서 ‘추적 거부 = 데이터 수집 없음’이라고 공개하지 않는다.
- 앱의 분석은 Firebase native SDK가 아니라 `MpGa4Analytics`의 GA4 Measurement Protocol이다. 설치별 client ID와 허용된 게임 이벤트를 보내고, client ID는 Save에 보관한다. IDFA·Game Center ID·연락처·계정 이메일을 분석 요청에 넣지 않는다. 최종 설정의 광고 기능 연결 여부도 별도로 확인한다.
- 기본 광고 SDK 외 mediation adapter가 없는 현재 구성에서 조사했다. 최종 archive에 예상 밖 SDK/manifest가 있으면 대조를 중단하고 추가 조사한다.
- root app manifest에는 추적 가능 제품임을 선언하고 앱 자체 GA4의 기기 식별자·상호작용을 분석 목적 수집으로 표시한다. SDK의 세부 유형과 목적은 각 SDK manifest에 포함된다.

회사 공통 개인정보 페이지는 여러 제품에 대해 거부 후 제한/비개인화 광고가 제공될 수 있다고 설명한다. 같은그림찾기 iOS 1.1.7은 거부 시 광고가 없으므로 앱별 한국어·영어 고지에 정확한 동작·분석 수집·Google UMP와 ATT의 구분을 보완한다. 새 버전이 공개되기 전에는 버전 범위를 분명히 표시한다.
