# App Store 1.1.6 준비 기록

아직 App Store Connect에 저장하거나 심사 제출하지 않은 초안이다. 대상은 앱 `1528539634`, `com.github.magicsih.MatchSymbol`, 예정 버전 `1.1.6`이다. 실제 릴리스 태그·빌드 번호는 중앙 발급 후 연결한다.

- 비교 범위: `v1.1.5`부터 승인 설계 MP-IOS-116 구현 후보까지. 스크린샷 캡처 도구 변경은 사용자 기능으로 소개하지 않는다.
- 실제 활성 언어는 `ko`, `en-US`다. `notes.source.json`의 `ko-KR`는 App Store Connect 입력 시 `ko`로 매핑된다. `release-notes.json`의 `markets.appStore`가 최종 What's New 원본이며 공통 `notes`도 같은 내용이다.
- 설명에서 실제 iOS 앱에 없는 친구 공유 주장을 제거한다. 기존 이름·부제·키워드·홍보·가격·국가·승인 후 자동 출시 설정은 별도 변경 대상이 아니다.
- 두 지원 URL과 한국어·영어 개인정보 URL은 2026-10-11 HTTP 200을 확인했다. URL의 도달 가능성은 Connect 저장 완료나 개인정보 답변 검수와 다르다.
- 출시 문구는 기록 실패 안내·시작 설정·조건부 광고 개인정보 진입·다음 판 광고 준비만 설명한다. 실제 UMP와 광고의 기기 검수는 아직 남아 있다.

최종 빌드에 맞춘 실제 스크린샷, 모든 언어의 문구·이미지·개인정보 검수, Connect 저장 후 일치 확인을 완료한 뒤 제출한다. 초안의 `pending` 항목을 통과로 간주하지 않는다.
