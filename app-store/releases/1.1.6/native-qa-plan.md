# 최종 iOS 후보 TestFlight 검수 — 실행 전 준비

아직 빌드·업로드·실기기 검수하지 않았다. 승인 설계 MP-IOS-116 v1의 AC-1~4를 축소하지 않고, 중앙 원장에 연결된 최종 1.1.6 source SHA·빌드 번호·artifact digest·TestFlight 접근을 확인한 뒤 실행한다. 개발 Editor의 대역 결과와 네이티브 SDK의 실제 결과를 구분한다.

현재 연결된 iPhone 12 Pro를 확인했다. iPad 실기기는 연결되지 않았으며 사용자에게 기기 연결 또는 직접 TestFlight 검수 가능 여부를 질문한 상태다. 다른 작업의 시뮬레이터·앱·계정을 조작하지 않는다. 기존 앱/사용자 저장은 초기화하지 않고, 기기별 기존 설치·언어·소리·기록 상태를 먼저 기록한다. 새 설치가 필요하면 실제 데이터 경로와 보존/복원 방법을 확인한다.
