# 1.1.6 App Store 문구 초안 검토

이 기록은 저장 전 텍스트 검토다. 실제 iOS 빌드·화면·이미지·Connect 저장값의 최종 검수는 아직 완료하지 않았다. 앱 1528539634, 예정 버전 1.1.6, 제품 후보 02e63ae만 대상으로 하며 빌드 번호는 아직 없다.

공식 업로더의 `load_notes()`로 release-notes.json을 직접 읽어 실제 적용 섹션 `markets.appStore`와 `ko-KR → ko`, `en-US → en-US` 매핑을 확인했다. 공통 notes fallback은 같은 문구다. 모든 활성 언어 ko/en-US를 포함하며 각 출시 노트는 네 줄이다. 설명·출시 노트의 길이, 다른 모바일 플랫폼·마켓 명칭 부재를 검사했다. 정확한 문구·문자 수·파일 SHA-256·확인 시각은 [텍스트 원장](metadata-text-review.json)에 보존한다.

설명은 기존 8개 심볼, 한 개 공통 심볼, 아래 카드 탭, 10정답, 완료 시간·구간·최고 기록과 언어·소리 설정만 말한다. iOS에 구현되지 않은 친구 공유 주장은 제거했다. 출시 노트는 이번 저장·시작 설정·조건부 개인정보 선택·광고 준비 복구의 실제 소스 변경에 연결된다. UI 대역 검수나 자동 검사로 실제 네이티브 UMP/광고 검수를 대신하지 않는다.

## 제출 전 남은 확인

- 최종 후보의 실제 iPhone/iPad 화면과 모든 활성 언어 이미지 내용·순서·치수·처리 상태.
- 기존 이름·부제·키워드·홍보 등 보존하는 필드의 실제 값과 정책 검토.
- 개인정보 개별 답변과 실제 SDK 동작의 일치.
- 저장한 설명·지원 URL·What's New의 GET read-back과 검수 원본 일치.
- 중앙 원장에 연결된 최종 VALID 빌드 선택과 기존 거절 제출 항목 확인.

[Apple 2.3 Accurate Metadata](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata)와 등록 스킬의 모든 언어·실효 노트·저장값 검수 조건을 적용한다. 이 문서로 문구 저장·심사 제출·출시 완료를 주장하지 않는다.

실제 정상 main의 카드 화면은 둥근 모서리 사각형으로 확인됐다. 초안의 `원형/circular` 표현은 정확하지 않아 양 언어에서 카드 모양 수식어를 제거했다. 심볼 개수·규칙·기록 설명은 유지하고 새 hash/문자 수를 원장에 반영했다. 네이티브 제출 이미지 검수는 여전히 별도다.
