# 개인정보 공개 화면 확인

2026-10-11 전용 Apple 브라우저 로그인 복구 후 앱 `1528539634` / Match Symbols의 `배포 → 앱이 수집하는 개인정보`를 읽었다. 공개 화면은 17일 전 게시 상태이며 다음 값이 표시됐다. 이 확인으로 새 버전이나 개인정보 답변을 저장하지 않았다.

- 영어 개인정보 URL: `https://www.seorilabs.com/en/privacy`.
- 선택 사항인 사용자 개인정보 선택 URL: 없음.
- 공개 미리보기: **사용자에게 연결되지 않은 데이터**. 추적 데이터 영역은 표시되지 않았다.
- 수집 유형 5개: 대략적인 위치(타사 광고), 기기 ID(분석·타사 광고), 제품 상호 작용(분석·타사 광고), 충돌 데이터(분석), 실적 데이터(분석).

개별 답변의 세부사항과 최종 iOS 빌드의 실제 SDK 동작 검수는 남아 있다. 세부사항 재확인 시 공용 프로필이 다른 로그인 작업 중이라는 응답을 반환해 추가 읽기를 중단했다. 위 공개 미리보기만으로 각 질문의 최종 read-back·새 바이너리 검증을 완료했다고 하지 않는다. 이 기록은 원래 게시된 상태의 일부 확인이며 심사 제출이나 승인을 의미하지 않는다.

## 2026-10-12 개별 답변 재확인

사용자가 전용 창을 다른 작업에서 사용하지 않는다고 답하고 자동화 모드 전환을 승인했다. 같은 Apple 전용 프로필에서 실제 로그인 계정·Seori Labs·앱 1528539634를 확인한 뒤 개인정보 질문을 읽었다. 각 유형의 편집 창에서 기존 체크·라디오 선택을 그대로 읽고 **취소**로 닫았다. 게시·저장·선택 변경은 없고 자기 브라우저 세션은 반납했다.

| 유형 | 기존 수집 목적 | 신원 연결 | 추적 |
|---|---|---|---|
| 대략적인 위치 | 타사 광고 | 아니요 | 아니요 |
| 기기 ID | 타사 광고, 분석 | 아니요 | 아니요 |
| 제품 상호 작용 | 타사 광고, 분석 | 아니요 | 아니요 |
| 충돌 데이터 | 분석 | 아니요 | 아니요 |
| 실적 데이터 | 분석 | 아니요 | 아니요 |

영어/한국어 개인정보 URL은 각각 `https://www.seorilabs.com/en/privacy`, `https://www.seorilabs.com/privacy`이고 선택 사항 URL은 모두 없다. [개별 답변·확인 시각·원본 해시](privacy-individual-readback.json)에 보존한다. **기존 답변 읽기는 완료했지만, 최종 1.1.6 네이티브 SDK가 이 답변과 일치하는지는 미검증**이다. `npa=1`만으로 비추적이나 사용자 연결 여부를 증명하지 않는다.

네이티브 일치 판단은 [Google iOS 데이터 공개 안내](https://developers.google.com/admob/ios/privacy/data-disclosure), [비개인화 광고의 식별자 사용 설명](https://developers.google.com/admob/ios/privacy/ad-serving-modes), [Apple의 개인정보 공개 정의](https://developer.apple.com/app-store/app-privacy-details/)를 적용한다. Google은 비개인화 광고에서도 노출 빈도 제한과 집계 보고에 식별자를 사용할 수 있다고 설명한다. 따라서 `npa=1`, ATT 요청 없음, 개인화하지 않음만으로 저장된 “신원 연결 아니요 / 추적 아니요”를 확정하지 않는다. 실제 빌드의 포함 SDK·privacy manifest와 앱의 설치별 GA4 client_id 전송을 함께 검수한다. 아직 답변 변경은 제안하거나 실행하지 않았다.
