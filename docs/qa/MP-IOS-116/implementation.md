## 테스트 우선 구현

`release_stability.tscn`을 기존 소스에서 실행해 요구사항 실패 17건을 확인했다. 최초 실행에서 테스트가 시작 전 게임의 splits를 요구하는 오류가 있어 테스트 시작 상태를 수정한 뒤 재실행했다. 이 환경/테스트 오류는 TDD 근거로 세지 않는다. 정상 재실행에는 SCRIPT ERROR/ERROR 없이 요구사항 실패가 나왔다.

실패: 쓰기 실패 시 메모리 보존, 일괄 저장 인터페이스, 정상 백업 보존, 최종 교체 실패 반환과 복구, 다음 판 광고 준비, 타이틀 설정, 실제 판 완료의 단일 쓰기/이전 기록/실패 알림/신기록 표시, iOS·Android 순위 시장과 AdMob 요청 분류, 표면 판정.

구현 후 `npm run check` 통과. 코어·엔진·한 판 통합·저장/광고/설정/시장 회귀를 실행했고 경계 14파일, 글리프 189종, 효과음 재현, AdMob/순위표 번들, 데이터 공개 선언, 중앙 workflow caller 4개도 통과했다. 실제 SDK/기기/스토어 검수의 대체 근거가 아니다.

## 실제 실행 환경

Godot 4.7.2 Editor Run에서 `tests/review_sandbox.tscn`을 사용한다. 제품 화면과 입력 경로는 그대로 두고 저장은 메모리, 광고 SDK는 대역으로 격리한다. F1 개인정보 필요 상태, F2 저장 실패, F3 양식 완료, F4 양식 실패, F7 렌더 캡처, F8 저장된 기존 기록으로 타이틀 복귀다. 가짜 UMP 양식이나 실제 노출 성공을 그리지 않는다. 이러한 대역 결과를 실기기 UMP/광고 노출 통과로 기록하지 않는다.

원본 사용자 저장과 프로젝트를 피하기 위해 회차용 프로젝트 복사본의 override.cfg에 회차 전용 사용자 데이터 디렉터리를 지정한다. 실행 소스·에셋은 후보 SHA와 동일하게 유지하고 격리 설정만 별도로 기록한다. 각 회차 계획·기능/UX 결과는 독립 검수자가 기록한다. 3회차 뒤 미완료 조건이 있으면 4회차 전에 별도 승인을 받는다.

## 남은 단계

UI 독립 검수 3회, 최종 HEAD의 로컬 Claude 교차 리뷰, 한국어 Ready PR·CI·병합, 최종 후보 전체 기능 E2E·중앙 검증, App Store 빌드/업로드/처리, TestFlight iPhone/iPad, ko/en-US 문구·실제 스크린샷·지원 URL·개인정보 read-back, 심사·승인·공개·live를 별도로 진행한다. 중앙 gate의 미실행/차단을 통과로 표시하지 않는다.
